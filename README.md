# Gemini Skills

Gemini app skills I built and use.

| Skill | What it does |
|---|---|
| [stage-ios-screens](./stage-ios-screens) | Designs 3 to 5 iOS app screens in realistic iPhone frames from one prompt, following Apple's design rules with real-feeling data. |

## Install

In the Gemini app: **Customize → Skills → Create → Upload**, then pick the skill folder or a zip with `SKILL.md` in its main folder.
